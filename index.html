A purpose-locked AI tool turning sprint data and retro notes into a deterministic sprint-health report — planned vs. reactive load, per-person capacity, recurring retro themes, and a data-backed commitment recommendation. Deterministic scripts handle the data; the chat layer only interacts with results, so numbers are never hallucinated. Includes a QE coverage spotlight distinct from raw story-point ownership.
Upgrade Coverage Validator shipped · team-wide rollout
Checks whether a project's fail-fast tests actually cover the changes in a Spring Boot patch release before anyone trusts fast feedback over full regression — comparing release notes against actual dependencies, then flagging change-specific and class-level coverage gaps with a clear per-project pass/fail verdict.
